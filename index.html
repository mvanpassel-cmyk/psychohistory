Psychohistory

Forecasting for global health. Read the news, write down calibrated probabilities for things that can be checked, and review what came true. The point is not the forecast but the track record: how well calibrated you and Claude are.

News comes from the GH Ribbon feeds, refreshed hourly. Forecasts are stored only in this browser; use Export to keep a copy. Claude's forecasts rest on headlines and its own knowledge, which can be outdated: treat them as a second opinion to be scored, not as an answer.
